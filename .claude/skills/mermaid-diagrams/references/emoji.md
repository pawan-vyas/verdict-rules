# Emoji Usage Guidelines

### Purpose of Emojis

- **Visual Recognition:** Quick identification of service types
- **Space Saving:** Reduce text while maintaining clarity
- **Professional Balance:** Use sparingly, not excessively

### Recommended Emojis by Category

#### Infrastructure & Compute
```
☁️ Cloud, ACI, Azure, AWS
🖥️ Virtual Machines, Servers, Daemon
💻 Frontend, Client, Desktop
🔧 Backend, API, Service
⚙️ Application Layer, Processing
```

#### Data & Storage
```
🗄️ Database, SQL
💾 Data Layer, Storage
📁 Volumes, Folders
📂 File Share, File Storage
💿 Persistent Volumes
```

#### Networking & Communication
```
🌐 Frontend Tier, Web
🔌 Proxy, Gateway
🔗 Connection, Link
📡 API, Communication
```

#### Security & Management
```
🔐 Key Vault, Secrets
🔑 Authentication, Keys
🛡️ Security
🔒 Encryption
```

#### Monitoring & DevOps
```
📊 Observability, Metrics, Jaeger
📈 Monitoring, Charts
📉 Logs, Analytics
🚀 Deployment, CI/CD
```

#### Azure-Specific
```
🔷 Azure (generic)
📦 Container Registry
☁️ Blob Storage
🏗️ Resource Group
```

### Emoji Placement

**In Subgraph Titles:**
```
subgraph ACI["☁️ Azure Container Instance"]
```

**In Node Labels:**
```
Backend["🔧 Backend API<br/>(.NET 9)<br/>Port: 8080"]
```

**Spacing Rule:** One emoji per element, at the beginning.
